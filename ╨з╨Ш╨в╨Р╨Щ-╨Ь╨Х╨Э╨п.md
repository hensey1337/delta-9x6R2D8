# АНТИ-ЗЕРГ — сайт

7 страниц, данные живьём из Google Таблицы. Меняешь таблицу — сайт обновляется сам.

---

## Что где лежит

```
index.html      главная, 7 кнопок
qwe.html        состав QWE (с гирскором)
dd.html         состав DD (с гирскором)
dark1.html      1DARKNES (без гирскора)
dark11.html     11DARKNES (без гирскора)
blacklist.html  антиприоритетные таргеты
targets.html    приоритетные таргеты
strategy.html   стратегия + диаграмма связей

assets/css/style.css   оформление
assets/js/data.js      адреса листов, парсер таблицы, цвета классов
assets/js/render.js    отрисовка страниц и схемы
assets/img/hero.jpg    кот-рыцарь для главной
```

Старые `script.js`, `style.css` и `cat.png` из репозитория можно удалить — они больше не используются.

## Как поставить пароль

Нужен Node.js. В терминале, в папке с файлами:

```bash
npm install -g staticrypt
```

Затем, там же где `index.html`:

```bash
staticrypt *.html -r \
  -d . \
  --short \
  --template-title "АНТИ-ЗЕРГ" \
  --template-instructions "Введите пароль" \
  --template-button "Войти" \
  --template-placeholder "Пароль" \
  --template-remember "Запомнить меня" \
  --template-error "Неверный пароль"
```

1. Скрипт спросит пароль — введи свой. Он никуда не сохраняется, кроме самих файлов.
2. Спросит, перезаписать ли файлы — согласись (`y`).
3. Появится файл `.staticrypt.json` с солью. **Сохрани его**: если будешь шифровать снова с тем же паролем, галочка «Запомнить меня» продолжит работать.

Потом залей на GitHub уже зашифрованные файлы.

Каждая страница шифруется отдельно, пароль у всех один — вводится один раз, дальше работает «Запомнить меня».

## Как менять данные

Всё в Google Таблице, сайт трогать не нужно.

**Листы составов** (QWE, DD, 1DARKNES, 11DARKNES) — сетка по две пачки в ряд:
- строка с названием пачки: `Group 1 КП BIOKAZAX` или `1 КП BIOKAZAX` — цифра становится номером, остальное названием;
- ниже шапка `Nickname / Class / GS` (в 1DARKNES и 11DARKNES вместо GS — `Comment`, там гирскор не выводится);
- 6 строк с бойцами.

Колонки можно менять местами и добавлять колонку с номером — сайт находит их по названиям в шапке.

**Блэклист и приоритетные** — три колонки: `Nickname / Setup / Reason`.

**Стратегия** — по строке на двойку: `Group / group composition / Squads / Target1 / Target2 / Notes`.

## Цвета классов

Определяются по названию класса:

| цвет | что красим |
|---|---|
| оранжевый | всё, что урон: SNS/GS-дд, spear, dagger, staff, bow-дд, xbow |
| синий | танки: SNS/WAND (паладин), SNS/GS (танк) |
| зелёный | хилы: BOW/WAND, holy, nature |
| серый | не распознано |

Правила лежат в `assets/js/data.js` в функции `classKind`. Если пишешь класс нестандартно и он попадает не в тот цвет — допиши нужное слово в список `WEAPONS` или поправь условие.

## Диаграмма связей

Строится автоматически из листа «Стратегия» и висит под карточками:

- слева двойка и её пачки;
- в центре цель №1;
- справа цель №2 (включается, когда первая убита);
- если одну цель бьют несколько двоек, у неё стоит метка `×N` и рамка ярче;
- цвет класса на узле подтягивается из составов, если такой ник там есть.

## Если данные не грузятся

Доступ к таблице открыт (`access-control-allow-origin: *`), с GitHub Pages всё работает. Если на странице ошибка:

1. Проверь, что таблица всё ещё опубликована: Файл → Поделиться → Опубликовать в интернете.
2. Google обновляет опубликованную копию с задержкой в несколько минут — правки появляются не мгновенно.
3. Открой консоль браузера (F12) — там будет текст ошибки.
